# Gemstone: A Different Path, bug reports

Found a bug in Gemstone? [Open a bug report](../../issues/new?template=bug.yml).

The in-game "Report a bug" button fills most of it in for you. Screenshots can be dragged into the form. Full logs and F9 reports are saved in your Gemstone "Bug Reports" folder.

Please don't post personal information. Your GitHub username is visible on public issues.
